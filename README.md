# LearnHub

LearnHub is an interactive learning aggregator platform designed to help students and professionals master core Computer Science subjects. It provides a structured roadmap, curated resources, practice environments, and progress tracking to streamline the learning journey.

## 🚀 Features

-   **Comprehensive Subject Coverage**: Detailed curriculums for:
    -   **Data Structures & Algorithms (DSA)**
    -   **Database Management Systems (DBMS)**
    -   **Operating Systems (OS)**
    -   **Computer Networks (CN)**
    -   **Web Development**
    -   **Software Engineering**
-   **Curated Learning Resources**: Hand-picked video tutorials and playlists from top educators like Striver, Love Babbar, Apna College, and more.
-   **Structured Learning Path**: Topics organized by difficulty (Easy, Medium, Hard) to guide your study flow.
-   **Interactive Coding Environment**: Built-in coding practice with **Monaco Editor** support for multiple languages.
-   **Knowledge Assessment**: Topic-wise quizzes to test and reinforce your understanding.
-   **AI Career Navigator**: Personalized career guidance and progression paths.
-   **User Profile & Dashboard**: Track your learning progress, completed topics, and quiz scores.
-   **Admin Panel**: Content management system for administrators to update resources and topics.

## 🛠️ Tech Stack

-   **Frontend**: [React](https://reactjs.org/) (with [Vite](https://vitejs.dev/) for fast tooling)
-   **Routing**: [React Router](https://reactrouter.com/)
-   **Styling**: Modern CSS3 (Custom responsive design)
-   **Icons**: [Lucide React](https://lucide.dev/)
-   **Code Editor**: [Monaco Editor React](https://github.com/suren-atoyan/monaco-react)
-   **PDF Handling**: [PDF.js](https://mozilla.github.io/pdf.js/)

## 📦 Installation & Getting Started

1.  **Clone the repository**
    ```bash
    git clone https://github.com/pranjal605/learnhub-project.git
    cd learnhub-project
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Start the development server**
    ```bash
    npm run dev
    ```

4.  **Open in Browser**
    Visit `http://localhost:5173` (or the port shown in your terminal) to view the application.

## 📂 Project Structure

-   `src/pages`: Individual page components (Landing, Dashboard, SubjectSelection, etc.)
-   `src/components`: Reusable UI components (Navbar, etc.)
-   `src/data`: Static data files for subjects, topics, and quizzes (`learningData.js`)
-   `src/App.jsx`: Main application component with routing configuration.
